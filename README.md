# telegram_keylog

## О проекте

**telegram_keylog** — это простой проект для логирования нажатий клавиш пользователя и отправки полученных данных в Telegram с помощью бота. Основная часть написана на Python, а дополнительные скрипты — на Shell.

## Возможности

- Логирование нажатий клавиш на компьютере
- Автоматическая отправка логов в Telegram через бот
- Отправка фото с веб-камеры
- Отправка скриншота экрана
- Кроссплатформенность (Windows/Linux)
- Простой и понятный код

# ⚠️ Последняя версия проекта находися в папке keysMosh
**keysMosh** - это оканчательная версия проекта, которая была использованна в качестве локальной системы практоринга в образовательном учериждении во время проведения экзамена. Эта версия была опробована и протестирована на MOS OS 12.x.x

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/kernel-paniccc/telegram_keylog.git
   cd telegram_keylog
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   # Для работы с камерой и скриншотами могут понадобиться:
   pip install opencv-python pillow
   ```

3. Вставьте токен Telegram-бота и свой chat_id в соответствующие переменные в коде.

## Использование

Запустите основной скрипт, например:
```bash
python keylogger.py
```
или используйте shell-скрипт (если он есть в проекте):
```bash
bash run.sh
```
